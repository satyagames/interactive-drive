licence, and the URL it came from.

## Reference

Driving feel, camera and interaction mechanics were studied from Bruno Simon's
open-source folio-2019 (MIT) and **reimplemented**. No code, models, textures,
sounds, fonts or text were copied (CLAUDE.md rule 1).

## Audio

None yet. Every sound is synthesised at runtime by `src/audio/` (placeholder).
The files wanted, and where each should come from, are listed in
`public/audio/MANIFEST.md`; log each one here as it arrives.

## Art, fonts and brand

- Arena models, matcaps and AO bakes are generated by this project's own
  scripts (`blender/scripts/`, `tools/generate-matcaps.mjs`).
- Fonts: system UI fonts only so far; no font files are shipped.
- Deloitte logo: not yet supplied. It goes in `public/brand/` from an
  approved asset only (CLAUDE.md rule 4).
